## A. 논문 한계 (Limitations 섹션에 명시)

### A-1. 데이터 한계
- **DART 실적 = 분기 기준 (2026-07 전환)**: cond4의 DART 실적은 신호일 기준 가장 최근 공시된 정기보고서를 쓴다. 손익(매출·영업이익·순이익)은 **단일분기**(그 분기 3개월치, YoY는 전년 동분기比), 4~5월 구간만 사업보고서라 연간. 재무상태표(부채/자본)는 분기말 스냅샷, 영업현금흐름은 분기 보고서 특성상 **누적치**(단일분기 손익과 기간이 다름). 공시기한(분기·반기 45일, 사업 90일)이 지난 보고서만 사용해 look-ahead 차단. 이전(연간 전용) 대비 값이 연 5구간으로 갱신돼 신호 밀도 향상.
- **분기 순이익 일부 N/A (에코프로비엠·한화에어로 소수 분기)**: 적자·전환 분기 일부는 DART `finstate_all`이 순이익 라인을 반환하지 않음(법인세차감전·주당손익만 제공) → 순이익 N/A. 표시용 필드라 실험 영향 경미(영업이익률·YoY는 정상).
- **은행·금융지주 (신한지주, KB금융)**: "매출액" 계정이 없어 매출/영업이익률/영업현금흐름은 N/A로 둠 (이자수익+수수료수익을 임의 합산하는 것은 자의적이라 배제). 과거연도(FY2021~2022, IFRS17 전환 이전)는 구양식 계정명이라 순이익·자본총계 일부도 N/A.
- **적자 연도 PER**: 적자기업의 PER은 정의상 무의미 → N/A 처리 (LG화학·에코프로비엠·LG엔솔 일부 연도). 버그 아님.
- **PBR/ROE 산출 방식**: 자본총계는 지배+비지배 합계 사용(지배주주지분 아님) → BPS 소폭 과대 가능. ROE는 DART 직접 미제공이라 PBR/PER 역산(DuPont identity).
- **애널리스트 리포트 표본**: 소형주는 리포트 수가 적음 (알테오젠 41건, 두산에너빌리티 47건). 대형주 대비 컨텍스트 밀도 차이.
- **목표주가 소스 의존**: 네이버금융 크롤링 의존. 전 리포트(~3,500건) 목표가/주가 비율 스캔으로 소스 입력오류 1건(HYBE 3,000,003) 탐지·제외. 미탐지 오류 가능성 잔존.
- **dividend_yield**: 일부 N/A이나 LLM 프롬프트 미사용이라 실험 무영향.

### A-2. 방법론 한계
- **베이스라인은 참고 벤치마크**: 컨센서스(리포트 발행일)·골든크로스(크로스 발생일)는 신호 *시점*이 LLM(월별 고정)과 달라 직접 비교가 아님. → **ablation(cond1~4, 동일 시점·동일 종목)이 주력 결과**, 베이스라인은 보조.
- **다중비교 보정 미적용**: 검정 pair마다 독립적 연구질문이라 Bonferroni 등 미적용 (한 줄 명시).
- ~~**통계검정 표본 비독립성**: 조건 간 동일 종목·날짜 공유 → Mann-Whitney 독립 가정 위배. paired test(신호 flip 분석)는 future work.~~ → **해소 (2026-08-07, 앱-3 신호 전이 탭)**. 같은 (종목, 신호일) 720쌍을 짝지어 전이표 + 부호검정으로 재검증. Mann-Whitney 결론(리포트 marginal 무의미)이 독립 가정 없이도 4모델 전부에서 재확인됨. 다만 Mann-Whitney 자체는 그대로 두고 짝 비교를 병기하는 형태이므로, 보고서에는 "독립 가정 위배를 짝 비교로 보완했다"로 서술.
  - **⚠️ 짝 비교 설계 시 주의(실측으로 확인한 함정)**: 짝지은 표본에서 실제 20거래일 수익률은 **조건과 무관하게 동일**하다((종목, 날짜)가 같으면 주가도 같음). 따라서 수익률을 그대로 짝지어 Wilcoxon을 돌리면 **노출량(Buy 신호 수)이 결과를 지배**한다. 상승장이라 Buy를 많이 내기만 해도 실현수익이 오르기 때문. 실제로 리포트 추가(LOO) Wilcoxon은 gemma p=0.0178(\*)·claude p=0.0095(\*\*)로 유의하게 나오지만, 같은 구간의 Buy 신호 수가 gemma 115→262, claude **1→58**로 폭증한 것이 원인이다. → **부호검정(전환된 건만 대상, 노출량 무관)을 주력으로 쓸 것.**
- **Sharpe 단순 연환산**: 관측치 IID 가정, 시계열 자기상관·샘플링주기 mismatch 미보정 → 과대추정 경향.
- **cond4_blind 부분 식별**: 종목명은 가렸으나 시가총액·현재가로 LLM이 종목을 부분 식별 가능 → 완전 blind 아님.
- **초과수익 날짜 정렬**: 종목·지수가 동일 거래달력이라 가정(대형주 거래정지 무시 가능 수준).
- **표본 부족 셀**: n이 작은 셀(예: 일부 Sell n=2)의 Sharpe·통계는 불안정 → 표에 "표본부족(n=N)" 수기 주석.

## B. 보고서에 쓰면 좋을 강점·분석거리

### B-1. 방법론 엄밀성 (어필 포인트)
- **Look-ahead bias 전 경로 차단**: 현재가=신호일 당일 종가, 리포트=신호 전일까지, DART=공시기한(3/31) 기준 회계연도 매핑, 컨센서스 대조군도 당일 종가로 통일.
- **실행순서 비의존성**: 주가 캐시 앞쪽 backfill로 캐시 삭제·재실행 시 결정적 재현 보장.
- **기간 정합**: EXPERIMENT_END(2025-12-31) 단일 상수로 LLM·베이스라인 동일 기간.
- **생성/평가 디커플링**: 신호는 LLM이 할 수 있는 **절대 방향** 예측, 스킬 평가는 **시장초과수익(알파)** — 시장 데이터 없는 LLM에 상대 예측을 강요하지 않음.

### B-2. 분석 거리 (결과 해석)
- **무기술 벤치마크 호명**: compare의 "전체" 신호 평균(전 종목 × 월별 20일 수익률)을 "시장참여 벤치마크"로 명명 → cond1 Buy > 벤치이면 단순 상승장 편승이 아닌 **종목 선별 효과** 논증. (코드 불필요)
- **Confidence calibration**: 신호별 confidence 이미 저장됨 → 구간별(50~69/70~89/90+) hit rate 표 = "LLM 확신도가 유의미한가" 챕터 (compare에 함수 1개 추가).
- **Sell 신호 현실 해석**: 개인투자자는 공매도 사실상 불가 → Sell을 "보유 회피/수익 실현" 신호로 framing.
- **Sell 억제 아티팩트 제거 서술**: 절대 전환 + Buy/Sell 대칭화로 Sell 비율 변화 비교 (2차 0~4% → 3차).
- **Sell 이상치 사례 심층**: 에코프로비엠 2023, LG엔솔 2024-08, 삼성SDI 2025-10 등.
- **통계 병행**: 비모수(Mann-Whitney + Cliff's δ) + 모수(Welch t + Cohen's d) + effect size.

### B-3. 재현성
- 결과 CSV 옆에 메타데이터(JSON) 저장 권장: 모델명 / temperature / 프롬프트 커밋 해시 / 실행일. (프롬프트를 여러 번 바꿨고 멀티모델 예정이라 혼동 방지)

**원래 계획 (2026-07-11 착수 전 기록, 참고용):**

- **동기**: 현행 PER은 최근 사업보고서(연간) EPS 기준 후행값. 실적 급변 국면에서 시장 통용치와 괴리 — 삼성전자 예: 우리 43.1(285,000/6,605=FY2025 연간EPS) vs 토스·증권사 23.2(EPS~12,350=TTM/선행). 가격은 일치(286,500≈285,000) 확인됨 → **순수 EPS 기준 차이, 버그 아님**(연간은 "틀린" 게 아니라 하나의 합법적 관습, 다만 1~3월엔 15~27개월 묵는 staleness가 문제). 시장 정합성 + 정보 신선도(LLM 판단 왜곡 완화) 위해 TTM으로 전환.
- **결정 = A(백테스트·forward 둘 다 TTM)**. B(분리: 백=연간/forward=토스)는 forward가 백테스트를 검증하는 의미를 깨서 기각. 백테스트는 토스로 못 맞춤(과거 스냅샷 없음)이라 DART 재구성 필수 → forward도 같은 DART-TTM 코드로 통일.
- **연간(C) 결과 보존**: 1~4차(연간) 결과를 **덮어쓰지 말 것** → 5차(TTM)와 병기해 "결론이 PER 방식에 무관하게 유지되는가" robustness 비교군으로 활용. (논문: 초기 연간 → 시장정합 위해 TTM 전환, 두 기준 하 ablation 결론 대조)
- **방식**: TTM EPS = TTM 순이익 ÷ 발행주식수. TTM 순이익 = 최근 연간 + 최근 분기 누적 − 전년 동기 분기 누적 (예: Q1 공시 시점 = FY(n−1) + Q1(n) − Q1(n−1)). **DART 분기 주당이익 라인은 불안정**(2024 3분기누적 1,440 < 반기누적 1,419 모순 확인)하므로 EPS 라인 직접 사용 금지 → **순이익으로 재계산**. (PER = 시가총액/TTM순이익 = 현재가/TTM_EPS)
- **look-ahead**: 신호일 기준 공시된 보고서만 사용 (기존 `applicable_dart_period` 로직 재활용).
- **영향 범위**: `collect_financials.py`(get_dart_annual→TTM 변형), `update.py`(forward 경로) 수정 → **백테스트 financials 재수집 + 5차 실험(5조건×2모델) 재실행**(PER/PBR/ROE가 cond2+ 컨텍스트). 재실행 부담 없음 확인(flash-lite·Gemma 비용 0, Gemma만 시간).
- **ROE/PBR**: PBR은 자본총계(분기말 스냅샷)라 무영향. ROE=PBR/PER 역산이라 PER 바뀌면 자동으로 TTM ROE가 됨(더 정확). 순이익 정의는 **당기순이익(연결 전체) vs 지배주주순이익** 중 토스와 맞는 쪽 확인 필요(삼성 소폭 차이).
- **★ 최우선 = 전 데이터 필드 audit (PER만이 아니라 우리가 뽑는 모든 값이 증권사와 일치하는지)**:
  - **price**: FDR raw — 문제 없을 것 (삼성 285,000≈토스 286,500 확인). 그래도 스팟 확인.
  - **dart_fundamentals** (매출/영업이익/순이익/영업이익률/부채비율/영업현금흐름/YoY): 단일분기 기준. **증권사가 분기·연간·TTM 중 무엇을 보여주는지 기준 정렬**부터 맞추고 값 대조.
  - **financials** (PER/PBR/ROE/시가총액): 핵심 문제 구간. PBR·ROE도 **지배주주 vs 연결전체 정의 차이**로 어긋날 수 있음.
  - **방법**: 대표 종목 — 대형주(삼성전자) + 금융(신한지주, 매출 N/A 엣지) + 적자 바이오(알테오젠) — 로 **필드 하나하나 증권사와 대조**, 불일치는 원인(정의 차이 vs 버그)까지 규명. 이게 5차 재실행보다 먼저.
- **작업 순서 (검증 우선 — 풀 재실행 전 계산식·데이터 확정)**:
  1. DART 분기 순이익(누적) 신뢰성 검증 + TTM 계산식 구현
  2. **전 필드 audit**(위) — 삼성/신한/알테오젠으로 토스·증권사 API와 대조, 지배주주 vs 연결 정의 확정. 토스 API는 **검증용**이지 live 소스 아님
  3. 전 필드 일치 확인되면 → financials 재수집 + 5차 실험 재실행 → compare/breakdown/significance
