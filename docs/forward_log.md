### ⚠️ 알려진 이슈: Claude Haiku의 cond1(무컨텍스트) 거절

**증상**: 삼성SDI·LG화학·HYBE·알테오젠 4종목의 cond1(종목명+현재가만 제공)에서 `call_llm`이 JSON 파싱 실패로 3회 재시도 후 실패. 원인은 API 오류가 아니라 **Claude가 "판단할 데이터가 부족하다"는 산문 거절 응답**을 반환한 것 (JSON 형식을 안 지킴).

**해석**: cond1은 원래 "컨텍스트 없음" 베이스라인으로 설계된 조건 — 정보 부족이 의도된 설정인데, Claude Haiku가 다른 모델(Gemini/GPT)과 달리 이 조건에서 20% 확률(4/20)로 형식을 어기며 거절함. 모델별 행동 차이로 판단, 코드 버그 아님.

**처리**: 재시도 없이 결측 처리 (사용자 결정). forward_eval 집계 시 해당 4건은 자연히 신호 없음으로 반영됨.

**향후 참고**: 매주 반복 시 Claude cond1에서 유사 거절이 재현되는지 관찰 필요. 반복적으로 발생하면 프롬프트 레벨 대응(예: "정보가 부족해도 반드시 JSON으로 최선의 추정 응답" 문구 추가) 검토 여지 있으나, 현재는 **동결된 프롬프트를 건드리지 않기로** 결정.

### 데이터 정합성 검증 (밸류에이션 파이프라인)

주가 변동에 대해 PER/PBR이 정확히 비례하고 ROE가 불변임을 확인 (ROE = PBR/PER이라 주가 무관):

|------|-------|-------|------|
| 삼성전자 | 285,000 / 22.73 / 4.05 / ROE 17.82 | 255,000 / 20.34 / 3.62 / ROE 17.8 | 주가 -10.5%, PER·PBR 동일 비율 |
| 현대차 | 457,500 / 13.2 / 1.02 | 425,000 / 12.26 / 0.94 | -7.1%, 비율 일치 |
| 카카오 | 35,350 / 29.24 / 1.36 | 35,900 / 29.69 / 1.38 | +1.6%, 비율 일치 |

4모델 전부 동일 값(삼성 PER 20.34 / PBR 3.62) 산출 — 데이터가 모델 무관함을 재확인.

### 관찰 1: Claude cond1 거절 3주 연속 재현

- **07-05(4건)**: 삼성SDI, LG화학, HYBE, 알테오젠
- **07-12(5건)**: 삼성SDI, 기아, HYBE, HD현대중공업, 알테오젠
- **07-19(3건)**: 기아, HD현대중공업, 에코프로비엠

거절 종목은 매주 일부 바뀌지만 **현상 자체는 3주 내내 일관**(매주 3~5건). Claude Haiku가
무컨텍스트(cond1)에서 JSON 대신 "데이터 부족" 산문을 반환하는 것은 **안정적 모델 특성으로 확정**.
보고서 모델 비교 챕터의 정성적 소재로 활용 가능. 처리 방침은 기존과 동일(재시도 없이 결측 유지).

### 관찰 2: 하락 국면에서 모델별 리스크 성향 분화

시장이 빠진 주에 모델 반응이 뚜렷하게 갈림. **gpt-5.4-mini는 Buy를 4건까지 줄이고 Neutral 59건**
으로 판단 유보 쪽에 강하게 기울었고(전주 Buy 13), gemini는 Sell 64건으로 매도 편향,
gemma는 Buy 25 / Sell 43으로 상대적 균형 유지. 동일 입력에 대한 모델별 위험회피 성향 차이가
국면 변화에서 더 크게 드러남.

### forward_eval 중간 관찰 (참고용)

20거래일 성숙 신호는 아직 0건(전체 1189건 pending). 5거래일 수익률이 산출된 07-05 배치만 참고:

| 신호 | n | 5d 평균 | 5d 초과 |
|------|---|---------|---------|
| Buy | 57 | -4.50% | +5.37% |
| Neutral | 144 | -5.99% | +3.55% |
| Sell | 195 | -5.31% | +3.36% |

하락 국면에서 Buy가 가장 덜 하락하고 초과수익도 최고. 다만 **07-05는 TTM 전환 전 구 데이터**이고
5거래일·표본 중첩·검정 없음이라 **참고 수준**. 정식 평가는 20거래일 성숙 시점(8월 초~)부터.
